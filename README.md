<h1> Análise Exploratória de Dados: PIB e Empenho Municipal </h1>

Este projeto apresenta uma análise exploratória de dados socioeconômicos utilizando Python. O objetivo é compreender melhor a distribuição do PIB e do Valor de Empenho entre diferentes municípios, além de destacar padrões relevantes por meio de visualizações simples, porém informativas.

A base de dados é carregada diretamente de um arquivo .csv e, após a importação, realizo uma primeira inspeção geral das dimensões e das primeiras linhas, garantindo entendimento inicial da estrutura. Em seguida, aplico visualizações usando Matplotlib e Seaborn, permitindo observar a distribuição do PIB e do Empenho com histogramas acompanhados de curvas de densidade.

Além disso, realizo uma análise focada nos municípios com os menores valores registrados. Para isso, ordeno os dados e seleciono o grupo dos 10 municípios com os menores índices tanto de PIB quanto de Empenho. Esses resultados são apresentados em gráficos de barras que facilitam a comparação direta entre os municípios selecionados.

O projeto tem como finalidade exercitar técnicas de leitura, organização e visualização de dados dentro do ambiente Python, reforçando conceitos essenciais de análise exploratória e construção de gráficos para comunicar insights de forma clara.
