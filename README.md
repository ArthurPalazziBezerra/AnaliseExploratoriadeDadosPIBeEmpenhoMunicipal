# An-lise-Explorat-ria-de-Dados-PIB-e-Empenho-Municipal
Este projeto apresenta uma análise exploratória de dados socioeconômicos utilizando Python. O objetivo é compreender melhor a distribuição do PIB e do Valor de Empenho entre diferentes municípios, além de destacar padrões relevantes por meio de visualizações simples, porém informativas.
